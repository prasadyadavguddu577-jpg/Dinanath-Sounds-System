DINANATH SOUNDS SYSTEM WEBSITE UPDATE

This package contains index.html and the assets folder.

UPLOAD / REPLACE ON GITHUB (mobile):
1. Open your GitHub repository Dinanath-Sounds-System.
2. Delete the old index.html only if needed, then upload this new index.html and the entire assets folder. Do not upload the nested folder; upload the files from inside this package to the repository root.
3. Commit changes. Wait a few minutes, then refresh your published page.

IMPORTANT: this static website does not yet have an online Admin Dashboard. Changes to prices/photos require editing/uploading files. A secure Admin Dashboard with online photo upload and synced pricing requires connecting a backend (for example Firebase) and setting it up with credentials.
